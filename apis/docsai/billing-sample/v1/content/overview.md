# Billing sample overview

This is a sample private API. It exists to show how DocsAI handles an API that must stay internal.

- Its catalog entry is `classification: protected`, so no reader release ever contains it.
- Signed-in console users open it in **Schema Studio**, read it in the **Reference** view and try it in the **Test** view.
- The reader site has no login, so there is no way to show a private API to some readers and not others.

All names and numbers in this API are synthetic.
