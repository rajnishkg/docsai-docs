# Work with pull requests

A console branch lives in DocsAI until you push it. **Push & open PR** pushes it to GitHub and opens a pull request, so people who work on GitHub see the change there too.

Publishing in DocsAI and merging on GitHub are separate actions. The order used on this site: approve and publish in DocsAI, push and open the pull request, merge it on GitHub, then **Sync source**.

<Steps>

<Step>

## Push the branch

On your branch in **Content** (not the default branch), choose **Push & open PR** in the **GitHub Enterprise workflow** box. DocsAI pushes the exact commit without force and opens a pull request, or reuses the open one for the same branch. The console answers *Branch pushed and provider review opened. Publication still needs exact-commit approval.* and links **Open provider review ↗**.

![Branch pushed and provider review opened, with the Open provider review link](assets/docsai/v1/screenshots/pull-requests/01-author-push-and-open-pr.png)

</Step>

<Step>

## Review on GitHub

The pull request is named after the branch, for example *Documentation: work/author/components-page*, and lists the branch commits.

![The pull request on GitHub with its six commits](assets/docsai/v1/screenshots/pull-requests/02-reader-pull-request.png)

**Files changed** shows the same diff the reviewer approved in DocsAI.

![Files changed in the pull request](assets/docsai/v1/screenshots/pull-requests/03-reader-pull-request-files.png)

</Step>

<Step>

## Merge on GitHub

Merge the pull request on GitHub, or with the GitHub CLI. The command prints nothing when it succeeds:

```bash title="Terminal"
gh pr merge 1 -R rajnishkg/docsai-docs --merge
```

Use a merge commit, never a force-push to the default branch: sync only moves forward.

![The merged pull request](assets/docsai/v1/screenshots/pull-requests/04-reader-pull-request-merged.png)

</Step>

<Step>

## Sync the console

An admin chooses **Sync source**. Other open branches then choose **Update from published base**. See [Sync changes from GitHub](/docs/docsai/v1/sync-changes-from-github/).

</Step>

</Steps>

## If the push fails

- On the default branch the box says *Create a non-default working branch before pushing for provider review.* Choose **Start editing** first: the console never pushes the default branch.
- If the branch moved since you loaded it, the push is refused. Reload and push again.
- If the push succeeded but GitHub did not create the pull request, choose **Push & open PR** again. DocsAI reuses the pushed commit and creates or finds the pull request.
