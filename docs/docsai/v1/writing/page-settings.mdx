# Change page settings

Page settings hold everything about a page that is not its text: title, owner, classification, lifecycle, review date, reader section, page type, order and description. They live in the page's `catalog.json` entry.

<Steps>

<Step>

## Open Page settings

On your branch, open the page from **Tracked files** and expand **Page settings · published** below the editor (the summary shows the current lifecycle).

</Step>

<Step>

## Change the fields

| Field | What it does |
|---|---|
| Page title | The title in the sidebar and above the page. |
| Owner | The team responsible for the page. |
| Classification | **Public** pages can be published; **Private** (`protected`) pages never reach readers. |
| Lifecycle | **Draft**, **In review**, **Published** or **Archived**. Only Published pages are in a release. |
| Review date | When the page must be checked again. A passed date shows in **Health**. |
| Reader section | The sidebar group. Moving a page never changes its address. |
| Page type | The template the page follows, or **No page type**. |
| Order in section | Position inside the section: lower numbers first. |
| Page description | *One plain sentence shown under the title and used as the page's search description (at most 200 characters).* |

For the components page this site set the description, kept **Writing** as the section, cleared the page type and set the order to `50`.

![Page settings with the description, section, page type and order filled in](assets/docsai/v1/screenshots/page-settings/01-author-edit-page-settings.png)

</Step>

<Step>

## Save

Choose **Save page settings**. The console writes a catalog-only commit and answers *Page settings committed · …*. It starts a new review cycle like any other commit.

![Page settings committed message](assets/docsai/v1/screenshots/page-settings/02-author-page-settings-saved.png)

</Step>

</Steps>

<Callout type="info" title="Commit text changes first">

**Save page settings** is unavailable while the editor has uncommitted text. Commit your text, then change the settings.

</Callout>
