# Use the API playground

The API playground sends real HTTP requests from your browser to the API's test server and shows the response. It runs in your browser: DocsAI never sees your credentials. Open it with **Test Request** on an operation, or **Open API Playground** on the API overview.

## Choose the server

**API environment**, at the top right, lists the API's enabled mock and sandbox servers, here **Local mock · http://127.0.0.1:4020**. Requests go only to the chosen server. The left column lists every operation by tag; **Find an operation** filters it.

## Send a request that needs credentials

<Steps>

<Step>

## Send without credentials

Choose **List projects** and **Send**. The playground does not send the request: *Request failed. Required credentials are missing, or this authentication combination is unsupported. Required: consoleSession OR serviceToken. Use the Authentication fields.*

![Request failed because credentials are missing](assets/docsai/v1/screenshots/api-playground/01-reader-send-without-credentials.png)

</Step>

<Step>

## Open the credentials

Expand **Authentication · IAM credentials**: *Enter credentials from your IAM. Values stay in this page's memory unless you choose to remember them on this browser.* There is one field per scheme. The cookie scheme says *Unsupported authentication scheme*: a browser cannot send cookies to another site.

![Authentication · IAM credentials with the consoleSession and serviceToken schemes](assets/docsai/v1/screenshots/api-playground/02-reader-open-credentials.png)

</Step>

<Step>

## Enter a token

Type the token into **serviceToken**, without the `Bearer` prefix. For the Local mock any value works, for example `sandbox-token`. **Remember on this browser for 30 days** keeps it (*Stored only in this browser. Use sandbox keys, never production secrets.*); **Clear credentials and reset client** removes it.

![A token typed into the serviceToken field](assets/docsai/v1/screenshots/api-playground/03-reader-enter-token.png)

</Step>

<Step>

## Send again

Choose **Send**. The mock answers *200 OK* with the example project list. **Request Headers**, **Response Headers** and **Body** show the exchange; **Code Snippet** shows the same request as code.

![200 OK with the example project list](assets/docsai/v1/screenshots/api-playground/04-reader-response-with-token.png)

</Step>

</Steps>

## Limits

- The playground sends only to declared test servers. Any other destination is refused.
- Credentials go only into the credential fields. A token typed into a header or query parameter is refused.
- Cookie schemes cannot be sent from the browser, so operations that accept only a cookie session cannot be tried here.
- The server must allow the reader site's origin through CORS: *Direct API requests require CORS for this documentation origin.*
