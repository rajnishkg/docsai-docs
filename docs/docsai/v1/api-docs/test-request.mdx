# Send a test request

Every operation on an API reference page has a **Test Request** button. It opens that operation in the API playground, ready to send to the API's test server.

<Steps>

<Step>

## Open the API reference

Open the API in the sidebar, for example [DocsAI console API](/docs/docsai/v1/console-api/). The reference lists every operation by tag, with its parameters, request body, responses and examples.

</Step>

<Step>

## Choose Test Request

Find the operation, for example **Get the current session** (`GET /api/session`), and choose **Test Request**. The playground opens with that operation selected.

</Step>

<Step>

## Send

Check **API environment**, fill in any parameters and choose **Send**. The response appears below the request. See [Use the API playground](/docs/docsai/v1/api-playground/).

</Step>

</Steps>

**Test Request** is unavailable when the API has no enabled mock or sandbox server. Its tooltip says why. See [Declare test servers](/docs/docsai/v1/test-servers/).
