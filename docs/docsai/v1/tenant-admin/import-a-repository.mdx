# Import a repository

Open an existing GitHub repository as a DocsAI project. The repository must already have a valid `catalog.json` at its root on the default branch.

You need the **owner** role in the tenant and a verified GitHub connection. See [Connect GitHub](/docs/docsai/v1/connect-github/).

<Steps>

<Step>

## Browse the provider

Choose **Repositories**, then **Connect repository**. Make sure the provider shows **Verified at last check**, then choose **Browse repositories**. DocsAI lists the repositories the connection can read in alphabetical order, 30 at a time, each with its default branch. Choose **Load more repositories** until you see yours.

![Browse repositories with rajnishkg/docsai-docs and its Import & open button](assets/docsai/v1/screenshots/import-a-repository/01-admin-browse-repositories.png)

</Step>

<Step>

## Import and open

Choose **Import & open** next to the repository. The console shows *Cloning and validating the catalog…*, then opens the project in **Content**.

![The imported repository open in Content as the DocsAI docs project](assets/docsai/v1/screenshots/import-a-repository/02-admin-import-and-open.png)

</Step>

</Steps>

If the repository is already connected in your tenant, DocsAI reuses that connection and opens its project. That is what happened here: `rajnishkg/docsai-docs` was created from the console, so **Import & open** opened the existing **DocsAI docs** project and created no second one. To work on the same repository in a separate working copy, choose **New working copy** on its card in **Repositories**.

## When import is refused

| Message | Cause | Fix |
|---|---|---|
| CATALOG_REQUIRED | No valid `catalog.json` on the default branch. | Add one (see [catalog.json](/docs/docsai/v1/catalog-json/)), push, and import again. |
| Empty repository | The repository has no default branch yet. | Push a first commit. |
| QUOTA_EXCEEDED | The tenant reached a limit. | Ask your platform operator to raise it. |

After import, **Health** lists every remaining catalog, link and API problem of the default branch, with a **Go to file** button for each.
