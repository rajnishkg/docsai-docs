# Author quickstart

Write a page, get it reviewed and see it on the reader site. You need the **contributor** role on the project (the `writers` team has it).

<Steps>

<Step>

## Start a branch

Open **Content**, choose the project, type a short topic in **Start editing topic**, for example `install-guide`, and choose **Start editing**. The console creates `work/<you>/install-guide` and selects it. See [Create a page](/docs/docsai/v1/create-a-page/).

</Step>

<Step>

## Write

Choose **New page** for a new page, or select a file marked ✎ in **Tracked files** to change it. Write in **Plain language** (the visual editor) or **Markdown source**. See [Write in the visual editor](/docs/docsai/v1/visual-editor/).

</Step>

<Step>

## Commit

Describe the change in **Commit message**, for example `docs(writing): explain page settings`, and choose **Commit source changes**. A commit is saved on your branch; readers do not see it.

</Step>

<Step>

## Submit for review

Choose **Submit commit for review**. Reviewers get a notification. See [Submit for review](/docs/docsai/v1/submit-for-review/).

</Step>

<Step>

## After approval

A reviewer approves the exact commit and a publisher publishes it. Your page appears on the reader site under its section. To share the change on GitHub too, choose **Push & open PR**. See [Work with pull requests](/docs/docsai/v1/pull-requests/).

</Step>

</Steps>

<Callout type="info" title="One commit, one review">

If you commit again after submitting, the approval no longer applies. Submit the new commit.

</Callout>
